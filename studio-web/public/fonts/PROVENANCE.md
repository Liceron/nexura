# Bundled Devanagari fallback font

Noto Sans Devanagari, unmodified variable TrueType font, obtained 2026-10-04 from the Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

Original filename: `NotoSansDevanagari[wdth,wght].ttf`. The local asset filename is simplified; the font's internal names and contents are unchanged. Distributed under the SIL Open Font License in the accompanying OFL.txt. The CSS family alias is local to this application.

Served locally so the bundled Hindi examples render when the machine lacks Devanagari system fonts. No Google Fonts network request or other external font service is used by the browser. This is rendering support for Devanagari, not a claim of support for every Indian script or model language quality.
